# Grand Strategy Hub

A static content site with in-depth guides and mechanics explainers for Paradox Interactive's grand strategy games — Europa Universalis IV, Europa Universalis V, and Crusader Kings III.

## Tech Stack

- **Astro** — static site generator
- **Markdown content** — articles live in `src/content/articles/`
- **Cloudflare Pages** — free hosting with auto-deploy on every push
- **GitHub Actions** — nightly automation (content-gap agent, indexing agent)

## Project Structure

```
├── src/
│   ├── components/       # Reusable UI components (Header, Footer, etc.)
│   ├── content/
│   │   ├── articles/     # Article Markdown files (generated by generate-articles.js)
│   │   └── config.ts     # Content collection schema (frontmatter validation)
│   ├── layouts/          # Page layouts (BlogPost, etc.)
│   ├── pages/            # Routes (Home, Blog, Category, About, Contact, Privacy)
│   └── styles/           # Global CSS
├── public/               # Static files (robots.txt, favicon)
├── topics.json           # Article topics list (title, keyword, category)
├── generate-articles.js  # Script that calls DeepSeek API to generate articles
├── astro.config.mjs      # Astro configuration
└── package.json          # Dependencies and scripts
```

## Generating Articles

Articles are generated by calling the DeepSeek API. You need a DeepSeek API key:

1. Sign up at [platform.deepseek.com](https://platform.deepseek.com)
2. Add a small prepaid balance (minimum ~$2-5)
3. Create an API key under **API Keys**
4. Run the generator:

**Option A (easiest):** Create a `.env` file in the project root with your key:

```
DEEPSEEK_API_KEY=sk-your-key-here
```

Then run:

```bash
node generate-articles.js
```

**Option B:** Set the environment variable directly in the terminal:

```bash
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-your-key-here"
node generate-articles.js

# macOS / Linux
DEEPSEEK_API_KEY=sk-your-key-here node generate-articles.js
```

The script reads topics from `topics.json`, generates a ~1000-word article for each, and saves them as Markdown files in `src/content/articles/` with proper frontmatter (title, description, keywords, date, category, slug).

## Deploying to Cloudflare Pages

### Prerequisites

- A GitHub account
- A Cloudflare account (free)

### Steps

1. **Push the repository to GitHub:**

   ```bash
   git add .
   git commit -m "Initial commit"
   git remote add origin https://github.com/YOUR_USERNAME/grand-strategy-hub.git
   git push -u origin main
   ```

2. **Connect to Cloudflare Pages:**

   - Go to [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
   - Authorize Cloudflare to access your GitHub account
   - Select the `grand-strategy-hub` repository
   - Configure the build settings:

     | Setting | Value |
     |---|---|
     | **Framework preset** | Astro |
     | **Build command** | `npm run build` |
     | **Build output directory** | `dist` |

   - Click **Save and Deploy**

3. **Your site goes live** at `https://YOUR_PROJECT_NAME.pages.dev` (Cloudflare assigns a subdomain based on your project name — it may not be exactly `grandstrategyhub.pages.dev`).

4. **Update the site URL** in `astro.config.mjs` and `public/robots.txt` to match your actual `*.pages.dev` URL, then push the change. This ensures the sitemap and canonical URLs are correct.

5. **Every future push** to the GitHub repository automatically rebuilds and redeploys the site.

### Custom Domain (Optional)

Once you're ready to spend ~$10-15/year:

1. Buy a domain (Namecheap, Cloudflare Registrar, etc.)
2. In Cloudflare Pages → your project → **Custom domains** → **Set up a custom domain**
3. Follow Cloudflare's DNS instructions

## Google Search Console

Once the site is live:

1. Go to [search.google.com/search-console](https://search.google.com/search-console)
2. Add a property using the **URL prefix** method with your `*.pages.dev` URL
3. Verify ownership (Cloudflare Pages provides a verification method, or use the HTML tag method and add it to `src/components/BaseHead.astro`)
4. Submit your sitemap: `https://YOUR_SITE.pages.dev/sitemap-index.xml`

## Automation (Nightly Agents)

The project includes two automation agents that run on a schedule via GitHub Actions:

- **content-gap-agent.js** — pulls Google Search Console data, finds keywords ranking 11-30, and improves those articles via DeepSeek
- **indexing-agent.js** — checks sitemap URLs against Google's Indexing API and requests indexing for unindexed pages

These are set up in later phases (Phases 4-6) once the site has live traffic data.
